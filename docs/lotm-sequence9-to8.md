# RealScale × 《诡秘之主》：序列9→8开发范围

## 当前开发范围

本阶段只开发四条途径的序列9与序列8。序列7暂时封存，不删除历史注册 ID、物品模型或语言键，但不再作为当前可玩内容。

| 途径 | 序列9 | 序列8 |
|---|---|---|
| 愚者 | 占卜家 | 小丑 |
| 隐者 | 窥秘人 | 格斗学者 |
| 黑暗 | 不眠者 | 午夜诗人 |
| 死神 | 收尸人 | 掘墓人 |

## 晋升

- 初次使用序列9魔药建立途径。
- 序列9→8：普通魔药要求70/100消化。
- 直接使用未经调和的同途径序列8特性要求90/100，并降低灵性、记录不稳定次数。
- 完整特性可以在炼药装置中替代两种主要材料，仍需秘法瓶、神秘学催化符和灵性火种。
- 不允许跨途径或跳级；序列8不能晋升至序列7。

## RPG 扮演

每日消化奖励类别上限为：探索12、技能8、研究9、野外采集6，总计最多35点。玩家可通过 /lotm acting 查询每日进度，通过 /lotm skills 查询已解锁能力。

## 超凡生态

当前主动变种共十种：
- 序列9：星光鱿鱼、噩梦邪眼、夜枭、黑斑青蛙、布套人。
- 序列8：霍纳奇斯灰山羊、铁臂兽、四眼绿龟、红月咆哮者、告死乌鸦。

七种序列7专属变种不再由新实体生成事件分配。旧实体标签和掉落映射保留，避免破坏已生成实体数据。

## 遗迹与非凡特性

遗迹匣只掉落序列9或序列8完整特性：序列9为75%，序列8为25%。序列7特性不再从新遗迹匣获得。

## 序列7封存边界

- 序列7魔药和特性替代配方从当前数据包移除。
- 序列7物品 ID、模型和语言资源保留。
- 序列7专属生物变种停止新生成。
- 灵界晶矿的 biome modifier 关闭。
- 序列7晋升和技能不属于当前版本验收范围。

## 世界兼容

不修改 RealScale 原有地形密度函数、维度预设或气候系统。新矿物、植物和遗迹仍通过 NeoForge biome modifier 控制；关闭或覆盖功能不会回滚已经生成的区块。

## 验收

- Gradle 9.8 test、build 通过。
- 四条途径序列9建立与序列8晋升通过。
- 普通配方和完整特性替代配方均可炼制。
- 炼药装置燃料、输出槽、输入消耗、进度保存和拆除掉落正确。
- 十种主动变种与其材料掉落正确；封存的七种变种不再生成。
- 遗迹匣只产生序列9/8特性。
- 消化每日上限、灵性、玩家存档和死亡重生复制正确。
- 独立服务器启动；已有 RealScale 世界不受地形改动影响。

CI 静态检查通过不等于客户端实地验收完成。客户端仍需测试炼药 GUI、实际世界生成、存档重载和旧世界兼容。
