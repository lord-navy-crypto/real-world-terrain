# Cinematic Macro Landforms v2 — original Earth-inspired new-world geometry

**Implementation status:** source + versioned registries + pure-Java regression +
eight top-down preview maps + live NeoForge Anvil-chunk CI in Draft PR #75.
This does not certify in-game lighting, camera screenshots or fully realistic
geographic placement.

## What is actually new

The existing six large-scale shapes remain supported:
Wulingyuan-like quartz sandstone pillar districts, Guilin/Yunnan-inspired
limestone cone clusters, caprock mesas, incised canyons, extinct caldera rings,
and U-shaped glacial valley corridors.

v2 adds two **new, macro density-driven** archetypes:

- **Star dune fields:** crossing, wind-oriented sinusoidal ridges with radial
  star-dune arms, gentle interdune corridors and smooth regional outskirts,
  gated to dry warm continental upland terrain. Inspiration: real Namib
  sand seas, not a copy of Sumeru's fantasy sandstorm. Importantly the
  macro terrain is generated by noise density; there are **no** spawned
  sand blocks, storms, new fluids, water edits, or magical structures.
- **Twin tepui tablelands:** a pair of separated broad superellipse plateaus
  with steep continuous escarpments and a lower traversable saddle. Inspiration:
  the Guiana Shield sandstone table mountains and the stacked-distance visual
  language of open-world exploration games. The two caps are not claimed
  to reproduce a particular real tepui 1:1.

Archetype selection uses world-seeded warm/humid or hot/dry noise sampled at
each site's **fixed center**, plus the stable absolute-world region hash.
The same terrain generates regardless of chunk load order. The process preserves
sea floors and low elevations with continentalness + baseline-height gating.
Visual palette is still handled by the existing biome and surface rules.

## Old-world preservation

Existing JSON and Java resources `realscale:cinematic_landforms_v1`
and `realscale:tva_cinematic_landforms_v1` stay intact. V2 introduces
separate `CinematicLandformMathV2`, `CinematicLandformDensityV2`,
`realscale:cinematic_landforms_v2`, and
`realscale:tva_cinematic_landforms_v2`.
The current player-facing Natural Exploration **preset template** selects
v2 for *new* world creation. Existing `level.dat` world generation
configs already serialized with v1 settings are not changed by these new
files, and the other three player presets retain their previous noise settings.

The four selectable preset **IDs** remain fixed. RealScale does not remove
historical biome source wrappers, cave systems, End/Nether logic, USGS data,
terrain-lab pipelines, ecological features or the previous v1 resources.

## Testing and limitations

- Source-level tests compare every new v2 noise setting field with v1
  except the three deliberately redirected density pointers. Vanilla ore,
  caves, fluids, climate source, structures and biome palettes remain intact.
- A pure JDK smoke test scans many site hashes to check all eight categories,
  samples two tepui plateaus and their saddle, checks dune height variation,
  and checks **exact equality** with v1 for all six original relief functions.
- Both the original six and new eight PNG previews are generated from actual
  production math and exposed as CI artifacts. They are mathematical
  **relative-height views**, not actual NeoForge camera captures.
- The dedicated server boots a new player Natural Exploration world using
  the v2 setting ID, tests the serialized noise/biome registry identity,
  and checks real Anvil region chunk records.
- Outstanding before release: in-game visual screenshots from actual loaded
  regions, seed-to-seed samples and cloud/climate geometry quality,
  more accurate sandy biome selection, long-distance river drainage
  continuity, aquifer behavior on canyon floors, and maximum terrain density
  performance. The high-relief landscape is a **prototype**, not verified
  1:1 geography.
