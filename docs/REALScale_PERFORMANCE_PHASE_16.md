# Performance Phase 16 — Distinguish terrain seams from steep continuous slopes

The saved-heightmap continuity gate now retains the original first-difference ratios as diagnostics but evaluates chunk/grid seams using a second-difference residual: the boundary edge's slope is compared with the linear continuation from the immediately adjacent edges. This detects an actual step discontinuity while avoiding false positives when integer height increments naturally cluster at interpolation-grid boundaries on steep continuous DEM slopes.

The gate uses both mean and p95 residual ratios. Synthetic tests prove that abrupt 4-block and 16-block steps still fail, while a steep but linear boundary gradient passes. Interior curvature stencils are now restricted to edges whose previous/current/next coordinates all remain inside one interpolation cell; the edge immediately after a boundary is excluded because its stencil still contains the step. On the prior measured saved-world sample, this yields a 4-block curvature mean ratio of about 2.13 and p95 ratio of exactly 2.0, and a 16-block mean ratio of about 2.01 with p95 ratio about 1.73. The gate requires both mean ratio >1.8 and p95 ratio >2.0, so that sample is not classified as a systematic seam. The new metric still must pass the current multi-seed server regression; no terrain output is changed by this QA-only phase.
