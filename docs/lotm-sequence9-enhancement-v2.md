# LOTM Sequence 9–8 — RealScale 功能完善

本阶段只完善四条途径的序列9和序列8。所有功能仍在 RealScale 内部实现，不创建独立模组。序列7已封存，历史物品 ID 保留，但不参与当前可玩内容。

## 四条途径

| 途径 | 序列9 | 序列8 |
|---|---|---|
| 愚者 | 占卜家 | 小丑 |
| 隐者 | 窥秘人 | 格斗学者 |
| 黑暗 | 不眠者 | 午夜诗人 |
| 死神 | 收尸人 | 掘墓人 |

## 能力范围

- **占卜家**：灵视、灵摆、感知附近已生成的非凡矿物与植物；小丑阶段增加协调性表现和短暂缓降。
- **窥秘人**：观察附近特殊矿物、植物与遗迹；格斗学者阶段增加短暂机动性。
- **不眠者**：夜间视觉、机动性与更快灵性恢复；午夜诗人阶段强化短暂恢复并迟缓附近敌对生物。
- **收尸人**：感知附近亡灵并抵抗冻结；掘墓人阶段可削弱附近亡灵并获得短暂恢复。

所有技能由服务器执行，具有灵性消耗、冷却和有限扫描范围。技能是原著启发下的游戏化子集，不声称完整复刻原著。

## 玩家进度

玩家数据保存途径、序列、灵性、消化和特性不稳定记录。现有 v1 NBT 键保持不变；旧存档缺少灵性数据时默认恢复为满值。死亡重生复制进度。

晋升要求：
- 初次使用序列9魔药建立途径。
- 序列9→8：普通魔药要求70/100消化；直接使用未经调和的序列8特性要求90/100。
- 不能跨途径、不能跳级；当前版本不开放序列8→7。

## 扮演命令

- /lotm guide：系统说明。
- /lotm status：途径、序列、灵性、消化和特性不稳定记录。
- /lotm acting：消化进度与每日四类扮演奖励。
- /lotm skills：当前已解锁能力。
- /lotm materials：下一序列材料。
- /lotm config：当前服务器配置。

## 生态

当前主动生成十种序列9/8特殊生物变种；七种序列7专属变种暂停生成。生态选择使用纯群系 ID 查表，不访问 RealScale 地形密度函数。原版生物仍是外观占位，后续可以替换为原创实体模型和动画。

世界生成保留矿物、花朵和小型遗迹匣。灵界晶矿属于序列7封存资产，不再注入当前群系生成。

## 验收

必须通过 Gradle 9.8 test、build，资源图谱检查、配方和特性路径检查、独立服务器启动，以及实际客户端世界测试。CI 通过不等于客户端世界已验收完成。

**仍待实际客户端验收的项目：** 炼药 GUI 交互、所有配方实际炼制、存档重载、特殊生物自然出现频率、遗迹生成密度和旧世界兼容。
