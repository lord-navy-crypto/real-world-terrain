# RealScale Northern V4: Experimental Cave Biomes and Sky Island Morphology

Integrated NeoForge Java implementation, enabled **only in the unlisted experimental v4 world preset**. Six existing registered cave biomes are region-stably selected from lower vanilla lush/dripstone/rare volcanic caves; Deep Dark, surface Y>=40, rivers and oceans pass through unchanged. Cave-rock palette varies by 3D biome. This does not alter the existing large cave excavation algorithm.

Floating islands retain the historical offshore layout and biome safety gates; in v4 only, the surface profile becomes irregular and hanging stone skirts thicker, with patches of flowering azaleas. Everything remains chunk-local. The four official player presets and USGS measured world are unchanged. Legacy sources and presets remain intact.

Math smoke, graph checks and NeoForge compilation are automated. New experimental world ID: `realscale:tva_northern_fjord_experiment_v4_three_realms`. Dedicated server generation and multi-seed 3D inspection of this specific v4 preset remain release gates. Never use new worldgen experimentally on an important save.
