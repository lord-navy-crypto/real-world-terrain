# RealScale Terrain — continuity and 3D caves (experimental v1.2)
## Root cause
v0.6 Realism MAX used `minecraft:flat_cache` for its terrain height and XZ noise inputs. Flat cache samples once per 4x4 block column; feeding that unchanged into final density is capable of generating discontinuous square terracing. Changed all 12 flat caches (11 source inputs, 1 final height cache) to per-coordinate `minecraft:cache_2d`. The original `archive/v0.6` remains unchanged.
## Flattened summit repair
Prior `height_signal` hard-clamped at -0.8515625 / 14.8203125 and could produce flat plateaus. The original expression is now in `height_signal_raw.json`; `height_signal.json` uses a monotonic Hermite spline with gradually shrinking summit gradient.
## Mountain cave network
Introduced trilinearly interpolated 3D noises (two spaghetti channels and rarer cave cheese chambers). Cave density is shielded by actual terrain density and a bottom gradient. The final field is `min(terrain_density, cave_density)`. Pre-carving terrain density remains unchanged for preliminary structure-height prediction. Big Sur uses the same cave field but its own USGS height-based surface shielding.
## Scope and caution
Only vanilla blocks and existing Minecraft noise parameters. These are procedural caves; v0.8–v1.0 lithology and hydrology models are NOT yet integrated. Existing v1.1 worlds are not compatible with changed generation: MAKE NEW WORLDS. Static tests cannot prove client visual continuity, world saved chunks, biome transitions or performance. Test actual NeoForge server/Anvil chunks before promoting this as a release.
